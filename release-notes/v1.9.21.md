Tuning a CW spot now keeps your radio in the CW sideband you chose instead of forcing it to the other one, and the JTCAT data-mode indicator on mobile now matches your desktop setting.

## CW spots keep your CW-L / CW-R sideband

If you operate CW-L (which on Yaesu radios is the CW-R mode), clicking CW spots had started flipping the radio to CW-U on every tune — you'd set CW-L, tune a spot, and land back on CW-U. This was reported by AE4XO on an FTDX10.

POTACAT re-sends the mode after each tune on purpose — that's what stops a band change from leaving the radio in the wrong mode — but it was always sending plain "CW," which on Yaesu is CW-U, so it overrode your CW-R every time.

Now POTACAT preserves whichever CW sideband the radio is already in. Set the rig to CW-R (CW-L) once, and tuning CW spots keeps it there; if you run CW-U, that's kept too. Switching into CW from SSB still lands on plain CW, so set your preferred sideband once and it sticks from then on. This applies whether the radio is connected through Hamlib/rigctld or a direct serial CAT connection. The same handling now protects RTTY-R on the Hamlib path.

## JTCAT data-mode indicator matches your desktop on mobile

With JTCAT set to Plain USB on the desktop, ECHOCAT on a mobile device still showed "DATA mode (PKTUSB)" on every launch. The radio was actually doing the right thing — this was a display-only mismatch, because the desktop wasn't sending that setting to the phone. The desktop now includes it, so the mobile indicator reflects your real setting. Reported by AB9AI on an FTdx3000.
