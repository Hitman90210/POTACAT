Club Log's application key has been issued and deployed, so the Club Log upload that shipped in 1.10.5 is now fully active — plus three fixes straight from this week's field reports.

## 📒 Club Log is live

Club Log approved POTACAT's application API key and it's now being served to the app automatically — if you set up "Send QSOs to Club Log" in Settings ▸ Logging (email + an Application Password from clublog.org ▸ Settings ▸ Application Passwords), every QSO you log lands at Club Log in real time, and "Upload entire log now" backfills your history. This works on 1.10.5 too; no update required for it — it simply started working.

## 🍎 macOS: no more fake restarts on update

The first Mac auto-update field test found the failure mode: if POTACAT.app is running from Downloads (quarantined), from the mounted disk image, or from a folder your account can't write, macOS silently fails the update swap at restart and relaunches your old version. POTACAT now detects all three cases up front and tells you the actual fix ("move POTACAT.app into Applications…") instead of performing a restart that changes nothing. Updater activity is also logged now, so a report of "the update didn't take" comes with evidence.

## 🌙 Idle Mode: JS8 no longer flashes its window every 30 seconds

If your idle program was JS8, the idle session and the JS8 window's open-equals-start behavior fought each other: the session opened the window, the window's auto-start read as "the operator is back," the session cancelled and closed the window, and the idle timer reopened it — a quarter-second window flash, forever. The idle session now recognizes its own window's startup, runs JS8 quietly while you're away, and tears down properly the moment you actually return.

## 🏆 LoTW: real errors instead of "unexpected code -1"

When TQSL couldn't run at all — missing binary, or hung on a dialog window until POTACAT stopped it — the upload reported a meaningless "-1". It now tells the three cases apart: a missing/unrunnable TQSL names the path, a timeout says TQSL is probably showing a dialog and how to clear it, and every failure now includes TQSL's own last words in the result line.
